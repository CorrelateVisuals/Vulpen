- Left out on purpose:
  - `constexpr` on Vulkan create-info structs and on small predicates. They are legal, but no work moves to compile time, which is CPP06's bar, and a CPP05 block with both `const` and `constexpr` reads worse.

  - Const members that would need a new helper to be set in the initializer list: `Window::_window`, and the handles `Mechanics` makes in its constructor body.
  - `const` on by-value parameters: the codebase never writes it.
  - `Reader::name` in `Manifest.cpp`: it is assigned twice, but one const init would read worse.
