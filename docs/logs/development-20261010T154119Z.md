**Decisions for the lead (A00)**, each built as described, in plain words:
1. **A `Texture` nothing is connected to is no longer an error.** The `ide`'s two images wait for `present`, so the `ide` would not start otherwise. Such a `Texture` now samples nothing, as one does before its image is filled. What it costs: a forgotten connection shows as an empty image instead of an error at load. Saying no means another way to start with nothing presented: a blank image drawn every frame (a window-sized clear each frame for nothing), or modes adding the image nodes on `present` (much more code). Recommended: keep.
2. **The image part has C++ now, and takes a Rect (`area`)**, as the editor and the terminal do. Modes gives the dock its room, so it cannot also read the Perform panel's room inside the dock: the graph would loop, which the engine refuses. So the `ide` has two images, the panel's and one over the whole window, and at most one draws a frame. Saying no means a new small part that turns a Rect into the image's place, a new row in the recipe map. Recommended: keep.
3. **`present` takes effect as the next frame cooks**, from the graph as that frame runs it. A line typed in the terminal goes to the newest project, so the command cannot see the `ide`'s own connections; the next frame can. The view draws over the `ide` for that one frame. Saying no means an engine change letting a command read the view its node lives in. Recommended: keep.
4. **`view load` does not present the project by itself**: until `present <name>`, or a press on its tab, it draws over the `ide`, as before. Not built. Modes could present each view the `ide` hosts as it appears, a few lines. Recommended: yes, add it.
5. **`child remove` of the view presented is refused** until `: disconnect present`, as `node remove` refuses a connected node. Saying no means `child remove` drops the connection with the view, a rule unlike `node remove`'s. Recommended: keep, and look again with 4, since closing a project in the `ide` takes two lines.
6. **`f1` is edit mode and `f2` perform mode**, since perform mode leaves the terminal no room to type in. Recommended: keep, or name others.
7. **The modes node's `to` param holds ports joined by commas**, the images `present` connects a view to. It is the one param whose value is a list. Recommended: keep.
