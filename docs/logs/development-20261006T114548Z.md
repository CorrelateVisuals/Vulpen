**Decisions for the lead (A00)**, each built as described, in plain words:
1. **Images hold one byte a pixel for now.** That is what the font atlas at step 16 needs. A color picture cannot be uploaded until a part needs one; adding color now would add code nothing uses (C00). Recommended: keep, and add color with its first user, A15's loaders or the `image` part.
2. **An image goes by the port that fills it**, where a buffer goes by its connection. So connecting or disconnecting keeps an image's pixels, and a node that uploads once never has to again. Renaming the node or the port loses them, but then the node's code starts anew and uploads again. The other way would lose the image on every connect. Recommended: keep.
3. **A C++ node with no shader may fill an image**, which a connection takes to another node's `Texture`. That lets the `font` part own the one atlas every `glyphs` node samples, instead of each `glyphs` node uploading a copy of its own. A C++ node cannot do the same with a buffer, whose layout only a shader gives (RA03); an image needs none. Recommended: keep.
4. **An unfilled image samples as nothing.** Until its image is uploaded, a `Texture` holds 0, and `sample_linear` returns zero for it instead of reading an empty slot, which GLSL02 forbids. The cost is one check per sample, and a shader that reads `textures[]` by hand must check for 0 itself. Recommended: keep.
5. **Storage images (`image2D[]`) wait for A10**, the first row whose shaders write images (C00). Nothing before it needs them. Recommended: keep.
