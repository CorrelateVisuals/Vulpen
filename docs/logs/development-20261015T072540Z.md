**Decisions for the lead (A00)**, made while building. Each is built as written unless you say otherwise.

1. **`h` is a key, not a command.** The wheel and drags are not commands either, and a script presses it with `input key down h`. A command would need two names, one a part, since a command registers once by name. Recommended: keep.
2. **"Home" for the graph is pan 0 and zoom 1**, the view a graph first shows, not "fit every box in view". You wrote "home/default". Fitting every box is easy to add later. Recommended: keep, unless you meant fit.
3. **A press in the Perform panel takes the focus.** Keys typed after a click there go to it, not to the terminal or the editor. `h` needs this. Recommended: keep.
4. **The graph draws its own grid**, rather than a new `grid` part. A part could serve another canvas later, but now it would add a part, a contract and a connection for one user (C00, C04). Recommended: keep, and move it into a part once a second user comes.
5. **The grid's look**: 24 pixels apart, every tenth line stronger, in the `border` color at 30% and 60%, the lesser lines fading from 16 to 4 pixels apart. It has no theme role of its own. Recommended: keep; say if it should be fainter or brighter.
6. **glyphs now cuts a character at its Label's edge everywhere**, not only in the graph. Before, a character that did not fit whole was left out. One rule for all text; the editor, terminal and tabs give rooms of whole characters, so nothing there looks different today. Recommended: keep.
7. **A Label gained `cut`**, a contract change (RV05). A view that dropped `glyphs` before keeps its own older copy and runs as it did. But if that view syncs `glyphs`, its `contracts/Label.glsl` has to be updated by hand, since a sync never updates a view's contracts (the open item in [nodes and folders](../plans/nodes-and-folders.md#open)). No view in this repository has one. Recommended: keep.
8. **The select box adds to the selection, takes only boxes wholly inside it, and only boxes in view**, since the box is cut at the panel. The other ways: a box that replaces the selection, or one that takes every box it touches. Recommended: keep; say if touching should count.
