**Step 16's design**, as built next:
- **Contracts**, each a GLSL struct with a C++ mirror in `contracts/` that the loader holds to it (A2):
  - `Rect`: `ivec2 offset; uvec2 extent; uint role`. VkRect2D's names (VK04), and the palette role it is drawn in.
  - `Label`: `ivec2 offset; uvec2 extent; uint role; uint first; uint count`, plus `Character`: `uint code; uint label`.
  - `Font`: `uvec2 cell; uvec2 atlas; uint columns; uint first; uint count`.
  - `Palette`: one `vec4` a role. The role names live once, in `contracts/Palette.h`. GLSL indexes the roles by number and clamps to their count, so no read leaves the buffer (GLSL02).
- **Parts**:
  - `palette` reads `theme.ini` again once it changes and fills a color a role. A key that is no role, or a role left out, stops it, naming why.
  - `font` bakes printable ASCII from a monospace font in its folder (DejaVu Sans Mono) with stb_truetype, built static so two views' copies link into one binary. It fills an `R8_UNORM` atlas and one `Font`.
  - `rects` draws 6 vertices a Rect, and `glyphs` 6 a character. Both are shaders only.
  - `GpuLayout.glsl` gains what both share: a quad's corners, pixels to clip space, and `sample_nearest` (GLSL01).
- **The test**: the build compiles only views it knows when it configures, so a recipe dropped into a temp folder would have no shaders or modules built. The test does what the fixture's other tests do: it links the parts' folders, and their build outputs, into a temp view, beside a fixture node that writes a Rect and a Label. It runs only where a display is.

**Decisions for the lead (A00)**, in plain words:
1. **The test links the parts instead of dropping them**, since only views the build knows get built. It still adds nothing to keep in step with the library. Recommended: keep. Teaching the build to compile a dropped view in a temp folder would take a configure step per test.
2. **The palette's role count is written twice**, in `contracts/Palette.h`'s names and in GLSL's clamp, since a shader cannot read a C++ list. A count that drifts still never reads past the buffer while GLSL's is the smaller; GPU-assisted validation catches the rest. Recommended: keep.
