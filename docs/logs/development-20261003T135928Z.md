**Decisions for the lead (A00)**, each built and committed, so a no means a change back:
1. **B7 by absolute path and `node.folder()`**, with the watch left for the palette, as above.
2. **The log keeps `<file>` arguments resolved**: an absolute path, so a replay opens the same file on this machine. The cost: a log moved to another tree needs those paths edited. The way out is for `log save` to write them relative to the log.
3. **A refused line fails the command that sent it** (above).
4. **Addressing**: `:` alone names the host, a sent line inherits its command's view, and a sourced line stands alone. So a script sourced while a child is current edits the host, unless its lines name the child; a log's lines always do.
5. **`child add` of a missing `view.vlp` hosts an empty view** (a log must replay from an empty folder); `view load` refuses a missing one, so a typo still fails loud.
6. **The CLI's current view is the newest hosted one.** There is no prompt yet, so `child list` shows which it is.
7. **`recipe drop <recipe> <name>` takes the name every time**: a usage has no optional placeholder. The CLI examples now read `recipe drop triangle screen`.
8. **`view new` and `view load` take a folder**, the same in both.
9. **Node errors name the view's folder** (above).
