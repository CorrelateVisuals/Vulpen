**Decisions for the lead (A00)**
1. **Native C++**: the five decisions at the end of [the proposal](../plans/native-cpp.md#decisions-for-the-lead-a00).
2. **Time in the frame block.** All options are deterministic: each is a pure function of the 64-bit frame number, computed with integers on the CPU. `frame.index()` in C++ stays the 64-bit frame, exact for ever.
   - **A, recommended: the clock starts over each hour.**

     ```glsl
     uint hour;   // whole hours since the first frame; wraps after 490,000 years
     uint index;  // the frame within this hour, from 0
     float time;  // seconds within this hour, index / rate: 0 to 3600, to 1/4096 s
     ```

     - `time` never passes 3600, so its step is never coarser than 0.25 ms, for ever.
     - No state and no maintenance: the reset is arithmetic on the frame number.
     - Easy to debug: the values stay small, and `hour 5, frame 154567, 2576.117 s` says where a run is.
     - The cost: a cycle whose period divides an hour runs seamlessly across the reset (45 periods do, among them 1, 2, 5, 10, 30 and 60 s, and 2, 5, 10 and 30 minutes); any other jumps once an hour. `fract(frame.time / 10.0)` turns once every 10 s, seamlessly, for ever.
   - **B: whole seconds and a fraction** (`uint seconds`, `float fraction`). Any period of whole seconds is exact for ever, as `float(frame.seconds % 7u) + frame.fraction`. But the obvious `float(frame.seconds) + frame.fraction` brings the drift back without a sign, so every shader must remember the modulo.
   - **C: a 64-bit frame and a helper** (`uvec2` frame, `float cycle(uint period)` in `GpuLayout.glsl`). Exact for any period, but the Vulkan floor has no 64-bit integers, so the modulo takes many instructions and reads badly in a debugger.
   - **A later addition to A**, only once a recipe needs a period that does not divide an hour (C00): `uint seconds`, so `float(frame.seconds % 7u) + fract(frame.time)` is exact too.
   - A costs about 15 lines: `GpuLayout.glsl`, `Pipelines::write_frame` and its member list, and the T14 fixture's check.
