# Strategy

The goals say why Vulpen exists; [principles](principles.md) and [requirements](requirements.md) say how it is built.

## Goals

- **Goal-01 — C++ and GLSL in harmony.** C++ and GLSL are written side by side, without worrying about moving data from one to the other. If you know C++ and GLSL, Vulpen should feel familiar.
- **Goal-02 — A fractal basis.** Vulpen is fractal, and a basis for almost anything you can imagine that benefits from parallel computation or real-time visuals.
- **Goal-03 — Easy to attach.** Vulpen attaches easily to existing projects for visual generation and parallel computation.
- **Goal-04 — Generations from recipes.** Vulpen will eventually run Generations, built from recipes.
